# Proyecto Frontend - Angular

Este proyecto contiene la capa frontend de la aplicación, construida con Angular. 
Asegúrate de que el backend esté corriendo antes de iniciar el frontend, ya que el frontend se conecta con el backend para realizar las operaciones CRUD.

## Requisitos previos

1. Tener **Node.js** y **npm** instalados en tu sistema.
   - Si no los tienes, puedes descargarlos desde [nodejs.org](https://nodejs.org/).

2. Tener el **backend** corriendo. Para más detalles, revisa la documentación del **backend**.

## Pasos para ejecutar el proyecto

1. Clona este repositorio en tu máquina local:
   ```bash
   git clone https://github.com/tonysoft2018/tesffullstack.git (rama bernal_frontend)

Navega hasta la carpeta del proyecto Angular (frontden_bernal):
cd tesffullstack/frontden_aldo

Instala las dependencias necesarias utilizando npm:
npm install

Asegúrate de que el backend esté corriendo, ya que el frontend depende de él para interactuar con la base de datos.

Ejecuta el proyecto Angular:
ng serve

Accede a la aplicación desde tu navegador:
http://localhost:4200

Ahora podrás interactuar con la aplicación en el frontend.
